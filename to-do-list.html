TO-DO List

Aplicación web fullstack de gestión de tareas, donde el usuario puede organizar su día a día creando, editando, completando y eliminando tareas. A diferencia de los proyectos anteriores, este cuenta con un backend propio desarrollado en Node.js que persiste los datos en una base de datos, lo que lo convierte en una aplicación completa de principio a fin.

Tecnologías utilizadas

  • Frontend: HTML5, CSS3, JavaScript (ES6+), Bootstrap
  • Backend: Node.js, Express.js
  • Seguridad: Helmet (cabeceras HTTP seguras), Express-rate-limit (protección contra abuso de la API)
  • Persistencia: Base de datos para almacenamiento de tareas
  • Despliegue: Frontend en Netlify, Backend en Render

Funcionalidades

Gestión de tareas

La aplicación permite al usuario realizar las operaciones CRUD completas sobre sus tareas: crearlas, editarlas, marcarlas como completadas y eliminarlas. Todos los cambios se persisten en la base de datos, por lo que la información se mantiene entre sesiones.

Backend seguro

El servidor está protegido con dos capas de seguridad adicionales. Helmet configura automáticamente las cabeceras HTTP para proteger la aplicación frente a vulnerabilidades web comunes, mientras que Express-rate-limit previene ataques de fuerza bruta limitando el número de peticiones que un cliente puede realizar en un periodo de tiempo.

Despliegue en producción

El proyecto está desplegado en un entorno real: el frontend está alojado en Netlify y el backend en Render, simulando una arquitectura de producción con servicios independientes y comunicación mediante API REST.
