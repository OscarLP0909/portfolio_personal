F1 Project

Aplicación web desarrollada como proyecto final del primer bloque del Máster en Full Stack Development, con el objetivo de consolidar los conocimientos adquiridos de HTML, CSS y JavaScript, haciendo uso también de Bootstrap. La aplicación consume la API pública de OpenF1 para obtener datos reales de la temporada.

Tecnologías utilizadas

  • HTML5 y CSS3 – Estructura y estilos de la interfaz
  • JavaScript (ES6+) – Lógica y consumo de la API
  • Bootstrap – Maquetación responsive
  • OpenF1 API – Fuente de datos de pilotos y resultados

Funcionalidades

Aviso de cookies

La aplicación incluye una página de aviso de cookies que el usuario debe aceptar antes de acceder al contenido, cumpliendo con las buenas prácticas de privacidad web.

Página de contacto

Formulario de contacto integrado en la aplicación para que los usuarios puedan comunicarse directamente.

Parrilla de pilotos

Listado completo de los pilotos que participan en la temporada actual de Fórmula 1, con información obtenida en tiempo real desde la API de OpenF1. Cabe destacar que esta API es gratuita pero presenta una limitación: durante sesiones en activo (carreras, clasificaciones, etc.) el acceso requiere una suscripción de pago.

Comparador de resultados

Herramienta de comparación que permite seleccionar dos pilotos y visualizar sus resultados en la última carrera disputada. En el ejemplo siguiente se muestra la comparativa entre Verstappen y Alonso.
